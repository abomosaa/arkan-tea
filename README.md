## نبذة عن المشروع

أركان هي منصة واجهة متجر إلكتروني فاخرة تم تصميمها وتطويرها لتقديم تجربة تسوق حديثة وسلسة. يركز المشروع على تجربة المستخدم الشاملة وتصميم الواجهات، متضمنا واجهة رئيسية متقدمة، ونظام فرز ذكي، وتصميما متجاوبا بالكامل، مع دعم ثنائي اللغة فوري (عربي وإنجليزي).

---

## المميزات الرئيسية

- واجهة رئيسية عصرية بنظام شبكي حديث (Bento Grid Layout).
- مساعد ذوق تفاعلي مدمج في الواجهة لتصفية المنتجات حسب تفضيل ومزاج المستخدم.
- دعم كامل للغتين العربية والإنجليزية مع التبديل الفوري لاتجاه الواجهة (RTL / LTR).
- سلة مقتنيات جانبية منبثقة بتحديث فوري وتنبيهات تفاعلية غير معطلة للتصفح.
- كتالوج منتجات متكامل مع فلاتر دائرية سريعة وخيارات ترتيب وبحث متقدمة.
- صفحة إتمام طلب وسداد إلكتروني متعددة الخطوات تدعم بوابات الدفع المعتمدة وكوبونات الخصم.
- شحن مجاني تلقائي للطلبات التي تتجاوز 100 ريال.
- صفحات متوافقة مع لوائح التجارة الإلكترونية وحماية البيانات (الخصوصية، الشروط والأحكام، صفحة 404 مخصصة).
- جاهزية لتطبيق الويب التقدمي (PWA) مع تهيئة متقدمة لمحركات البحث (SEO).

## طريقة التشغيل

المشروع واجهة ويب جاهزة للتشغيل المباشر دون الحاجة لأي حزم أو خطوات بناء:

1. افتح ملف `index.html` في أي متصفح ويب حديث.
2. أو شغل خادم محلي:
```bash
npx serve .
```

## About ARKAN

ARKAN is a modern luxury e-commerce storefront and digital experience designed for high-end retail. The platform blends editorial minimalism with refined cultural identity, offering an intuitive shopping journey, mood-based discovery, and seamless bilingual support.

---

## Key Features

- Editorial hero section and contemporary Bento Grid layout.
- Integrated sensory taste assistant for mood-based product discovery.
- Instant bilingual toggle (Arabic RTL / English LTR) with typography matching.
- Slide-over cart drawer with real-time updates and non-disruptive toast alerts.
- Dedicated product catalog with circular category filters and quick search.
- Multi-step checkout supporting local payment gateways, coupon codes, and order receipts.
- Automatic free shipping threshold on orders above 100 SAR.
- Regulatory compliance pages (Privacy Policy, Terms of Service, Custom 404).
- Progressive Web App (PWA) ready and SEO optimized.

---

## Tech Stack

- HTML5 Semantic Structure
- Tailwind CSS & Custom CSS Variables
- Vanilla JavaScript (ES6+ State & Event Architecture)
- Lucide Icons

## Getting Started

Run directly in any modern web browser without dependencies:

1. Open `index.html` in your browser.
2. Or serve locally:
```bash
npx serve .
```
