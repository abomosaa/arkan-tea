## 🌟 نبذة عن المشروع (About The Project)

**«أركان | ARKAN»** هي إعادة صياغة بصرية وتجربة مستخدم شاملة (UX/UI Overhaul) لعلامة تجارية متخصصة في أرقى محاصيل الشاي الجبلية والقهوة المختصة وأدوات التحضير الخزفية الحرفية.

يمزج المشروع بين **عراقة التراث المعماري النجدي وكرم الضيافة العربية**، مع **أحدث معايير التصميم العالمي للعلامات التجارية الفاخرة (Ultra-Luxury Minimalist & Editorial)**.

---

## ✨ المميزات الرئيسية (Core Features)

1. **مساعد الذوق التفاعلي المدمج (Sensory Mood Sommelier):**
   * نظام ذكي مدمج في قسم الأكثر طلباً يتيح للمستخدم تحديد مزاجه الحالي:
     * 🌿 **استرخاء وسكينة (Calm & Relax):** توليفات البابونج والخزامى والشاي الأبيض الفضي.
     * ☕ **صفاء وتركيز (Focus & Clarity):** الشاي الأسود العتيق وأولونغ الجبال الصخرية.
     * ⚡ **طاقة وانتعاش (Vibrant Energy):** ماتشا أوجي الاحتفالية وتوليفة الهيل والزعفران.
   * إشارات بصرية واضحة، تفاعل فوري، وشريط تأكيد يوضح عدد المحاصيل المطابقة مع إمكانية إعادة التعيين بضغطة زر.

2. **دعم ثنائي اللغة لحظي (Bilingual AR / EN):**
   * تبديل فوري بين العربية (RTL) والإنجليزية (LTR) بضغطة زر دون إعادة تحميل الصفحة.
   * ملاءمة خطوط الطباعة العربية (`Readex Pro` / `Tajawal`) والإنجليزية (`Playfair Display` / `Plus Jakarta Sans`).

3. **سلة مقتنيات فاخرة منبثقة (Slide-over Cart Drawer):**
   * مؤشر تفاعلي لحساب الشحن السريع المجاني (للطالبات فوق 200 ر.س).
   * دعم أكواد الخصم الترويجية (جرب كود: `ARKAN10` لخصم 10%).
   * تعديل الكميات وحساب المجموع بدقة لحظية.

4. **شبكة التصنيفات العصرية (Bento Grid Layout):**
   * استعراض أحدث الأنماط البصرية لعام 2026 لمختلف فئات الشاي والأدوات المحمولة.

5. **صفحة كتالوج شاملة ومستقلة (`catalog.html`):**
   * فلاتر دائرية تفاعلية سريعة، فرز حسب السعر والتقييم، واستكشاف كامل لجميع المحاصيل.

6. **نظام تصميم وموجهات لـ Google Stitch و Figma (`stitch-design-system.md`):**
   * رموز الألوان والخطوط (Design Tokens) وموجهات ذكاء اصطناعي جاهزة للنسخ لتوليد المزيد من الشاشات.

## 🚀 التقنيات المستخدمة (Tech Stack)

* **الهيكلة:** HTML5 Semantic Structure
* **التنسيق:** Tailwind CSS (Modern Utility-First Engine) + Custom CSS
* **الأيقونات:** Lucide Icons
* **التفاعل:** Modern Vanilla JavaScript (Modular ES6 State Engine)
* **الخطوط:** Google Fonts (Readex Pro, Playfair Display, Plus Jakarta Sans)

```text
├── stitch-design-system.md     # وثيقة نظام التصميم وموجهات Google Stitch / Figma
├── README.md                   # التوثيق والتعريف بالمشروع
└── assets/
    ├── css/
    │   └── styles.css          # التنسيقات المخصصة، الظلال، وحركات الأنيميشن
    └── js/
        └── app.js              # محرك الحالة، السلة، اللغات، ومساعد الذوق
```

## 💻 طريقة التشغيل (Quick Start)

المشروع مبني كواجهة ويب تفاعلية مستقلة؛ يمكنك تشغيله فوراً دون الحاجة لتثبيت أي حزم:
1. انقر نقراً مزدوجاً على ملف `index.html` في متصفحك المفضل.
2. أو قم بتشغيل خادم محلي خفيف:
   ```bash
   npx serve .
   ```
