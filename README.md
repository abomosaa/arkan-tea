## 🌟 نبذة عن المشروع (About ARKAN)

**«أركان | ARKAN»** هي منصة تجارة إلكترونية وتجربة مستخدم عصرية فائقة الفخامة (Modern Luxury UX/UI Web Experience) لعلامة تجارية متخصصة في أرقى محاصيل الشاي الجبلية والقهوة المختصة وأدوات التحضير الخزفية الحرفية.

يمزج المشروع بين **عراقة التراث المعماري وكرم الضيافة العربية**، مع **أحدث المعايير العالمية لتصميم واجهات المتاجر الراقية (Editorial Luxury & Minimalist Whitespace)**، متضمناً نظام تصفح ثنائي اللغة لحظي، وتفاعلات حسية مخصصة للعملاء.

## 📱 استعراض صفحات المنصة (Pages & Visual Showcase)

### 1. الصفحة الرئيسية (Home Page — `index.html`)
الواجهة التفاعلية الرئيسية للعلامة التجارية؛ تضم قسم الترحيب البصري (Hero Section)، ومساعد الذوق الحسي (Sensory Sommelier) المدمج لتوصيات المحاصيل وفق الحالة المزاجية، وشبكة التصنيفات البصرية (Bento Grid Layout)، مع قسم مخصص لحجز جلسات التذوق الخاصة لكبار الشخصيات (VIP Tasting Concierge).

![ARKAN Home Page](https://images.unsplash.com/photo-1576092768241-dec231879fc3?auto=format&fit=crop&w=1200&q=80)

* **أبرز العناصر:**
  * هيدر زجاجي عائم (Floating Glassmorphic Header) متجاوب بالكامل.
  * مساعد الذوق التفاعلي المدمج في قسم الأكثر طلباً.
  * شبكة Bento Grid لاستعراض أصناف الشاي النادر وأكواب السيراميك الحرفية.
  * سلة مشتريات جانبية منبثقة (Slide-over Cart Drawer) مع مؤشر الشحن المجاني.

صفحة استكشاف وتسوق متكاملة تتيح استعراض كافة المحاصيل والأدوات بمرونة عالية، مع فلاتر تصنيف دائرية مميزة وسريعة، وتصفية متقدمة حسب النكهات والمزاج، وخيارات ترتيب ديناميكية.

![ARKAN Catalog Page](https://images.unsplash.com/photo-1544787219-7f47ccb76574?auto=format&fit=crop&w=1200&q=80)

* **أبرز العناصر:**
  * فلاتر دائرية سريعة للتصنيفات (شاي أسود، أولونغ، شاي أبيض، قهوة مختصة، ماتشا، وأدوات تحضير).
  * خيارات ترتيب حسب السعر والتقييم وأحدث المحاصيل.
  * بطاقات منتجات تفاعلية تدعم المعاينة السريعة (Quick View Modal) مع النوتات العطرية والارتفاع الجبلي.
  * تكامل فوري وتلقائي مع سلة المشتريات الرئيسية.

تجربة سداد إلكتروني متعددة المراحل تتسم بالبساطة والوضوح والأمان العالي، وتدعم خيارات الشحن المتعددة ووسائل الدفع الإلكتروني المعتمدة محلياً وإقليمياً.

![ARKAN Checkout Page](https://images.unsplash.com/photo-1556742049-0a67c5574f73?auto=format&fit=crop&w=1200&q=80)

* **أبرز العناصر:**
  * نموذج شحن ذكي بخطوات واضحة ومقسمة.
  * بوابات دفع متنوعة: (بطاقات مدى، Apple Pay، فيزا وماستركارد، تمارا للتقسيط، والدفع عند الاستلام).

  * ملخص مالي لحظي يتضمن حساب ضريبة القيمة المضافة (15%) وتكلفة الشحن.
  * نافذة إيصال رقمي مؤكد فور إتمام العملية برقم مرجعي مميز (`ARK-2026-XXXX`).

## ✨ المميزات الرئيسية للنظام (Core Features)

1. **مساعد الذوق التفاعلي (Sensory Mood Sommelier):**
   * تصفية ذكية للمحاصيل بناءً على الحالة الشعورية والمزاجية للعميل:
     * 🌿 **استرخاء وسكينة (Calm & Relax):** محاصيل خالية من الكافيين، خزامى، وبابونج عضوي.
     * ☕ **صفاء وتركيز (Focus & Clarity):** أولونغ جبال وويي والشاي الأبيض الفضي النادر.
     * ⚡ **طاقة وانتعاش (Vibrant Energy):** ماتشا احتفالية يابانية ومحاصيل قهوة إثيوبية مجففة.
   * إشعار بصري مباشر بعدد المحاصيل المطابقة وإمكانية إلغاء التصفية بضغطة واحدة.

2. **دعم ثنائي اللغة لحظي (Bilingual Instant Switching):**
   * تبديل فوري بين العربية (RTL) والإنجليزية (LTR) بضغطة زر واحدة دون الحاجة لإعادة تحميل الصفحة.
   * تناسق طباعي بين خطوط `Readex Pro` و `Playfair Display`.

3. **سلة مشتريات تفاعلية (Smart Cart Drawer):**
   * حساب تلقائي للكميات والأسعار.
   * شريط تفاعلي لحساب المبلغ المتبقي للحصول على الشحن السريع المجاني (فوق 100 ر.س).
   * دعم أكواد الخصم والتحقق منها برمجياً.

4. **تطبيق ويب تقدمي (PWA Ready):**
   * ملف `manifest.json` وأيقونات مهيأة تتيح تثبيت الموقع كتطبيق مستقل على أجهزة الجوال والحواسيب.

5. **أمان عالي وتهيئة لمحركات البحث (SEO & Hardened Security):**
   * تعقيم كامل للنصوص والبيانات البرمجية لمنع ثغرات Cross-Site Scripting (XSS).
   * بيانات وصفية منظمة بتنسيق JSON-LD للمنتجات والمؤسسة.
   * ملفات `sitemap.xml` و `robots.txt` لتسهيل فهرسة محركات البحث.

## 🚀 التقنيات المستخدمة (Tech Stack)

* **بنية الصفحات:** HTML5 Semantic Markup
* **التنسيق والأنماط:** Tailwind CSS + Custom CSS Variables & Animations
* **الأيقونات:** Lucide Icons Vector Library
* **التفاعل:** Vanilla JavaScript (Modern ES6+ State & Event-Driven Architecture)
* **الخطوط:** Google Fonts (Readex Pro, Tajawal, Playfair Display, Plus Jakarta Sans)

## 📂 هيكل الملفات (Project Structure)

```text
├── index.html                  # الصفحة الرئيسية وتجربة الترحيب ومساعد الذوق
├── catalog.html                # صفحة كتالوج المحاصيل وفلاتر الاستكشاف
├── checkout.html               # صفحة إتمام الطلب وبوابات الدفع الإلكتروني
├── privacy.html                # وثيقة سياسة الخصوصية وحماية البيانات
├── terms.html                  # وثيقة الشروط والأحكام وسياسة الاسترجاع
├── 404.html                    # صفحة الخطأ المخصصة 404
├── manifest.json               # ملف تهيئة تطبيق الويب التقدمي (PWA)
├── sitemap.xml                 # خريطة الموقع لمحركات البحث
├── robots.txt                  # تعليمات روبوتات الفهرسة
├── stitch-design-system.md     # دليل نظام التصميم ورموز الهوية البصرية
├── README.md                   # التوثيق الشامل واستعراض الواجهات
└── assets/
    ├── css/
    │   └── styles.css          # التنسيقات المخصصة والمؤثرات البصرية والحركية
    └── js/
        └── app.js              # محرك إدارة الحالة، السلة، التوطين اللغوي، والفلترة
```
